JSON Import

Upload cards from structured .json

Intended for card sets generated by AI/LLMs or other tools. This is additive and separate from full backup import.

Accepted JSON import format 
{
  "schema": "flashcram.cards.v1",
  "deck": "Deck name",
  "cards": [
    {
      "front": "Question",
      "back": "Answer",
      "hint": "Optional retrieval cue; omit when unnecessary",
      "tags": ["tag1", "tag2"],
      "format": "plaintext"
    }
  ]
}

Prompt preferences guide generation only and do not restrict accepted imports. Use format as plaintext or markdown. Backup JSON files should be imported from Settings.

hint is an optional string shown through a collapsible hint button at the bottom of the front. Omit it, use null, or use an empty string for no hint. Hints follow the card's Plain text / Markdown format, including math and Mermaid; they do not replace the required front or back. Other hint value types are invalid. Escape quotes and newlines as for other card text.

Optional Mermaid diagrams go inside front or back as fenced mermaid blocks on Markdown cards. No additional JSON fields are needed. Put blank lines around the block; encode line breaks as \n in JSON. Images and raw SVG are not supported by authoring JSON.

Supported: flowcharts/trees, sequence, state, class, entity relationship, mindmap, pie, and XY charts. Limits: four diagrams per face, 10,000 characters per diagram, 100 edges. Diagrams are optional; ordinary cards need no changes.

Example card object for the cards array:

{
  "front": "Show the two branches of a binary tree.",
  "back": "Each node has at most two children.\n\n```mermaid\nflowchart TD\n  Root --> Left\n  Root --> Right\n```",
  "tags": [
    "trees"
  ],
  "format": "markdown"
}
